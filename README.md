# KitPlugin

Plugin Minecraft na kity z GUI edycji i podglądu.

## Funkcje

- `/kit` — menu z listą kitów
- `/kit create [nazwa] [item]` — tworzy nowy kit
- `/kit edit [nazwa]` — GUI edycji
- `/kit [nazwa]` — podgląd z potwierdź/anuluj

## Komendy

| Komenda | Opis |
|---|---|
| `/kit` | Menu z kitami |
| `/kit create [nazwa] [item]` | Tworzy kit |
| `/kit edit [nazwa]` | Edycja kitu |
| `/kit [nazwa]` | Podgląd i odbiór |
